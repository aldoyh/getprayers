# تطبيق الصلاة الإسلامي



تطبيق إسلامي شامل لمواقيت الصلاة والأيام الإسلامية المباركة مع واجهة مستخدم متجاوبة باللغة العربية.

## الميزات

- عرض مواقيت الصلاة حسب الموقع الجغرافي
- عرض الأعياد والمناسبات الإسلامية
- واجهة مستخدم متجاوبة تعمل على جميع الأجهزة
- دعم كامل للغة العربية من اليمين إلى اليسار
- تصميم أنيق بأسلوب Dark Theme

## Running Locally

After cloning the repo, install dependencies:

```bash
npm install
```

Then, run the application in the command line and it will be available at <http://localhost:5173>.

```bash
npm run dev
```
